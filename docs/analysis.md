# 修了試験（科目A免除試験）21回分の分析と予測

データ確認日：2026-10-21
対象：IPA「修了認定に係る試験（基本情報技術者試験に係る問題）」令和3年7月〜令和8年7月の21回分（問題冊子 PDF）

## 1. 集計方法

1. 問題冊子（スキャン画像の PDF）を 300dpi で画像化し，Tesseract（日本語）で OCR した（`tools/ocr_menjo.sh`）。
2. 「問N」の見出しで問題を切り出した（`tools/analyze_menjo.py`）。1,400問中 1,382問を切り出せた（見出しが読めなかった18問は直前の問題に含まれる）。
3. 選択肢を含む問題全文の文字3-gramの Jaccard 係数（0.5以上）で同じ問題をまとめた。同じ回の問題同士はまとめない。
4. 中分類は自動判定のあと，異なる問題 958問をすべて目で確認して約270問を手で直した（`data/menjo_overrides.txt`）。

- 令和6年6月〜令和8年1月は，問題の半分以上が過去の修了試験と同じ問題だった。同じ問番号で再出題されることも多い。
- 令和8年6月・7月は再出題がほぼなくなり，新しい問題に入れ替わった。
- 異なる問題は 958問，そのうち 290問が2回以上出題されていた（OCR の誤りで同じ問題を別扱いにした例があるので，実際はもう少し多い）。

### 3-3. 特定の問題の予測は難しい

過去のデータで「出題回数が多い順に200問」を選んで次の回を当てる検証をすると，60問中 15〜27問しか当たらなかった。再出題は過去の全回からまんべんなく選ばれている。したがって次の方針をとる。

- 分野別の出題数は配置表どおりと予測する（確度が高い）。
- 個々の問題は，3回以上出題された過去問 108問と，最新の R8.6・R8.7 の 120問を優先して練習する。
- 新問が出ても対応できるよう，テーマ別の頻出度（3-4）で弱点を埋める。

## 5. 限界

- 次回が「過去の修了試験からの再出題」型に戻るか，令和8年の「新問」型が続くかは公表されていない。
- テーマ別の回数は OCR テキストのキーワード一致による目安で，誤差がある。

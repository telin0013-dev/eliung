# 基本情報技術者試験 科目A 出題統計と予測

データ確認日：2026-10-21

## 1. 試験の形式

| 項目 | 内容 | 出典 |
|---|---|---|
| 科目A（本試験） | 四肢択一 60問・90分。採点対象は56問で、残り4問は将来の出題に使う試行問題 | IPA / STUDYing |
| 修了試験（免除試験） | 本試験の科目Aとほぼ同じ形式（60問・90分）。問題は IPA が提供または審査する。合格基準は100点満点中60点以上が一般的（講座ごとに要確認） | Wikipedia / kotora |
| 免除期間 | 修了認定日から1年間、科目Aが免除 | IPA |
| 受験回数 | 修了試験は2回まで受験可能 | IPA |
| シラバス | Ver.9.2（2026年1月8日掲載）。下請法を削除し、中小受託取引適正化法（取適法）を追加 | IPA 試験要綱・シラバス |

## 2. 集めた統計

### 2-1. 大分類の比率

| 集計対象 | テクノロジ | マネジメント | ストラテジ |
|---|---|---|---|
| サンプル問題60問＋令和5〜7年度公開問題（各20問）＝120問 | 78（65%） | 13（11%） | 29（24%） |
| 科目A 60問の一般的な内訳 | 41（68%） | 7（12%） | 12（20%） |

### 2-3. 過去問アーカイブの収録数（H21〜R8）

科目Aはプール問題から出題されるため、過去問と同じ選択肢がほぼそのまま再登場しやすい。収録数が多い分野ほど繰り返し出題されている。

旧午前試験の分析（富士通エフ・オー・エム）でも、中分類「セキュリティ」が最多の10問（80問中）だった年が続いている。

## 3. 予測（60問の中分類別出題数）

組み立て方：
1. 大分類は一般的な内訳 41 / 7 / 12 に合わせる。
2. テクノロジ系は、サンプル問題の実数（基礎理論9・コンピュータシステム10・技術要素18）に合わせて中分類へ配分する。
3. 技術要素18問のうち、収録数が最多で比重が高まっているセキュリティを10問、DB・NWを各4問とする。
4. マネジメント系・ストラテジ系は、過去問で繰り返し出るテーマの多さで配分する。

| 中分類 | 予測 | 狙われるテーマ |
|---|---|---|
| 基礎理論 | 5 | 基数変換・2の補数・論理演算・誤差・待ち行列・AI |
| アルゴリズムとプログラミング | 4 | スタック/キュー・探索・整列・計算量・再帰 |
| コンピュータ構成要素 | 4 | CPI/MIPS・キャッシュ・割込み・並列化 |
| システム構成要素 | 3 | 稼働率・MTBF/MTTR・RAID・クラウド |
| ソフトウェア | 2 | ページ置換・スケジューリング・OSS |
| ハードウェア・HI・マルチメディア | 1 | 画像/音声データ量・UI設計 |
| データベース | 4 | 正規化・SQL・排他制御・障害回復 |
| ネットワーク | 4 | サブネット・プロトコル・伝送時間 |
| セキュリティ | 10 | 暗号・署名・攻撃手法・認証・ゼロトラスト |
| 開発技術 | 4 | テスト技法・アジャイル・UML・モジュール設計 |
| プロジェクトマネジメント | 2 | クリティカルパス・EVM・WBS |
| サービスマネジメント | 3 | SLA・インシデント/問題管理・バックアップ |
| システム監査 | 2 | 監査人の独立性・内部統制 |
| システム戦略・企画 | 3 | BPR・RPA・非機能要件・RFP・生成AI |
| 経営戦略・技術戦略 | 5 | SWOT・PPM・損益分岐点・BSC・IoT |

| **合計** | **60** | |

## 4. 限界

- この環境から IPA のサイトに直接アクセスできなかったため、公開問題の本文を1問ずつ分類したわけではない。数値は上記の公開済み集計を組み合わせた推定。
- 予測は IPA の公式な出題予告ではない。
- 練習問題は、上記テーマに合わせて作成したオリジナル問題（138問）。計算問題の答えはスクリプトで検算済み。仕上げには IPA の公開問題そのものも解くこと。

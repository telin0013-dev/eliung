# FE科目A 予測ドリル

基本情報技術者試験の科目A免除（修了試験）対策用の、スマホで動く練習アプリです。

- 公開統計から予測した **中分類別の出題配分（60問）** で模試を出題（90分タイマー・60%で合否判定）
- 予測テーマに沿ったオリジナル問題 **138問**（解説付き、選択肢は毎回シャッフル）
- 最頻出10問 / 苦手復習 / ランダム10問 / 分野・頻出度を選べるカスタム練習
- 解答履歴と分野別正答率を端末のブラウザに保存
- 統計・予測の根拠と出典は [docs/analysis.md](docs/analysis.md) とアプリの「分析」タブ

## 使い方

`dist/index.html` は1ファイルで完結しています。スマホのブラウザで開けば動きます（フォント以外は通信不要）。

GitHub Pages で配信する場合、Pages の公開元に指定できるのはリポジトリのルートか `/docs` だけなので、`dist/index.html` を `docs/index.html` にコピーしてから Settings → Pages で `/docs` を指定してください。

## 構成

```
src/stats.js      出題統計と中分類別の予測配分
src/questions.js  問題データ（o[0] が正解）
src/app.html      アプリ本体
build.py          src を1ファイルにまとめて dist/ に出力
```

問題や配分を変えたら `python3 build.py` を実行してください。

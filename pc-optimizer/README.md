# HexaTune

Windows 10 / 11 向けのPC最適化ツールです。レジストリ・サービス・電源プランなど 58 項目の設定を、1つずつ、またはプリセットでまとめて切り替えられます。

- **自動推奨設定**: CPU（Intel 11世代以下 / 12世代以降のハイブリッド / AMD Ryzen）、メモリ容量、HDD の有無を見て、合わない設定を自動で外してから適用します
- **すべて元に戻せる**: 変更前の値を記録してから書き換えます。「元に戻す」で、Windows の既定値ではなく**適用前に入っていた値**に戻します
- **復元ポイント**: プリセットの適用前に Windows の復元ポイントを自動で作ります（設定でオフにできます）
- **今の状態を読み取る**: スイッチの ON / OFF は、アプリが覚えている状態ではなく、実際のレジストリやサービスの値から判定します
- ゲームごとのCPU優先度、DNS の切り替え、Ping テスト、一時ファイルのクリーンアップ

## インストール

GitHub の **Actions → HexaTune (Windows)** の最新の実行結果を開き、Artifacts の `HexaTune-windows` をダウンロードします。

- `HexaTune-1.0.0-portable.exe` … インストール不要。そのまま起動できます
- `HexaTune-1.0.0-x64-nsis.exe` … インストーラー

起動すると管理者権限を求められます（HKLM やサービスを変更するため）。コード署名をしていないので、初回は SmartScreen の「詳細情報 → 実行」が必要です。

## 使い方のおすすめ

1. 「バックアップ・復元」で復元ポイントを作る（プリセットの適用時は自動で作られます）
2. 「自動推奨設定」で **Middle Tweaks** を適用 → 再起動して様子を見る
3. 問題がなければ **Low Latency** を試す
4. 体感が悪くなった設定は、各カテゴリの画面で個別に OFF にする

### プリセットから外れる条件

| 設定 | 外れる条件 | 理由 |
|---|---|---|
| 電源調整（Power Throttling）を無効化 | Intel 12世代以降・Core Ultra | Pコア/Eコアへの割り当て（Thread Director）に悪影響が出ることがある |
| メモリ圧縮を無効化 | メモリ 16GB 未満 | メモリ不足時にページファイルへの書き出しが増える |
| カーネルをページングしない | メモリ 8GB 未満 | 同上 |
| SysMain を無効化 | HDD がある | HDD ではアプリ起動の先読みが効いている |

## 入れていない設定

効果が無い、または逆効果なのに「定番」として出回っている設定は入れていません。

- **SystemResponsiveness = 0**: Microsoft のドキュメントでは 10 未満の値は 20 として扱われます。有効な最小値の 10 にしています
- **Win32PrioritySeparation = 0x26**: Windows のクライアント版の既定値（2）と同じ動作（短い・可変・3倍ブースト）になるため、変える意味がありません
- **QoS の「予約帯域 20%」を 0 にする**: Windows は普段から帯域を予約していません
- **TabletInputService の無効化**: Windows 10 では日本語入力（IME）が一部のアプリで使えなくなります
- **AutoEndTasks**: シャットダウン時に保存前のアプリを強制終了してしまいます

## 開発

```
cd pc-optimizer
npm install
npm start          # Windows で起動（管理者のターミナルから）
npm test           # 設定の定義と、適用・復元のロジックのテスト（どの OS でも可）
npm run dist       # Windows 用の exe を release/ に作る
```

`renderer/index.html` をブラウザで直接開くと、PC を変更しないデモモードで画面を確認できます。

```
main.js              Electron のメインプロセス（IPC）
preload.js           画面に公開する API
engine/tweaks.js     設定項目とプリセットの定義
engine/service.js    状態の判定・バックアップ・適用・復元
engine/tools.js      システム情報・クリーンアップ・DNS・ゲーム優先度・復元ポイント
engine/runner.js     PowerShell の呼び出し（スクリプトは標準入力で渡し、一時ファイルを作らない）
engine/engine.ps1    PowerShell 側の実行エンジン
renderer/            画面（HTML / CSS / JS）
test/windows-smoke.js  Windows 実機で全設定を適用→復元するテスト（CI 用。自分の PC では実行しない）
```

CI（`.github/workflows/pc-optimizer.yml`）では、使い捨ての Windows VM で全設定を実際に適用して元に戻すテストと、アプリを起動して各画面のスクリーンショットを撮るテストを行い、exe をビルドします。

## 注意

- 効果の大きさは PC の構成やゲームによって変わります。ベンチマークで大きく変わる設定ばかりではありません
- 会社や学校で管理されている PC では使わないでください（グループポリシーの値を書き込むため）
- ウイルス対策ソフトがレジストリの変更を警告することがあります
